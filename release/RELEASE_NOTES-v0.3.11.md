# VibeStick v0.3.11

This release packages the current Bridge, StickS3 firmware, native macOS installer, precompiled Mac helpers, offline Python runtimes, and ESP32-S3 flashing tools into one self-contained Apple Silicon download.

Highlights since the previous public package include:

- a precompiled universal StickS3 firmware with private per-device NVS configuration;
- a consumer installation path that does not download ESP-IDF or compile software;
- Codex approval controls, completion monitoring, quota/reset display, and distinct device sounds;
- configurable BMI270 spatial gestures and improved low-power behavior;
- front-button ChatGPT activation with idempotent composer focus;
- cloud, local Whisper, and WeChat Input voice workflows.

See `安装说明.md` or `INSTALL.en.md` inside the download before installing. This arm64 build is ad-hoc signed and is not Apple-notarized.
